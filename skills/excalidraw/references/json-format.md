## File Structure

```json
{
  "type": "excalidraw",
  "version": 2,
  "source": "https://excalidraw.com",
  "elements": [],
  "appState": {
    "gridSize": 20,
    "viewBackgroundColor": "#ffffff"
  },
  "files": {}
}
```

## Element Types

| Type | Use For |
|------|---------|
| `rectangle` | Services, components, databases, containers, steps |
| `ellipse` | Users, external systems, start/end points |
| `text` | Labels inside shapes, titles, annotations |
| `arrow` | Data flow, connections, dependencies |
| `frame` | Logical groupings (preferred over dashed rectangles) |

**BANNED**: Never use `type: "diamond"` - arrow connections are broken.

## Element Properties

Excalidraw's `restoreElements()` function auto-fills missing properties with defaults when loading files. This allows for minimal JSON that renders correctly.

### Required Properties (must include)

| Property | Description |
|----------|-------------|
| `id` | Unique identifier string |
| `type` | Element type: `rectangle`, `ellipse`, `text`, `arrow`, `frame` |
| `x`, `y` | Position coordinates |
| `width`, `height` | Dimensions (except for arrows) |

### Styling Properties (include to override defaults)

| Property | Default | Description |
|----------|---------|-------------|
| `strokeColor` | `#1e1e1e` | Border/line color |
| `backgroundColor` | `transparent` | Fill color |
| `fillStyle` | `solid` | Fill pattern |
| `strokeWidth` | `2` | Line thickness |
| `strokeStyle` | `solid` | Line style: `solid`, `dashed` |
| `roughness` | `1` | Hand-drawn effect (0=smooth) |
| `opacity` | `100` | Transparency (0-100) |
| `fontFamily` | `5` | Font (5=Nunito for diagrams) |
| `fontSize` | `20` | Text size |

### Relationship Properties (include when needed)

| Property | When to Include |
|----------|-----------------|
| `boundElements` | When shape has bound text or arrows |
| `containerId` | On text elements inside shapes |
| `frameId` | On elements inside a frame |
| `startBinding`, `endBinding` | On arrows connected to shapes |

### Auto-Generated Properties (safe to omit)

These fields are regenerated by `restoreElements()` when the file is loaded:

| Property | Purpose | Safe to Omit? |
|----------|---------|---------------|
| `seed` | Random value for hand-drawn look | **Yes** |
| `version` | Edit counter | **Yes** |
| `versionNonce` | Random nonce for versioning | **Yes** |
| `updated` | Timestamp | **Yes** |
| `isDeleted` | Deletion flag (default: `false`) | **Yes** |
| `locked` | Lock flag (default: `false`) | **Yes** |
| `groupIds` | Group membership (default: `[]`) | **Yes** if empty |
| `link` | URL link (default: `null`) | **Yes** if null |
| `roundness` | Corner style (default: `null`) | **Yes** if null |
| `angle` | Rotation (default: `0`) | **Yes** if 0 |

### Full vs Minimal Example

**Full format** (as exported by Excalidraw):
```json
{
  "id": "box-1",
  "type": "rectangle",
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 80,
  "angle": 0,
  "strokeColor": "#1e1e1e",
  "backgroundColor": "transparent",
  "fillStyle": "solid",
  "strokeWidth": 2,
  "strokeStyle": "solid",
  "roughness": 1,
  "opacity": 100,
  "groupIds": [],
  "frameId": null,
  "index": "a0",
  "roundness": { "type": 3 },
  "seed": 1820827870,
  "version": 90,
  "versionNonce": 1517217154,
  "isDeleted": false,
  "boundElements": [{ "type": "text", "id": "box-1-text" }],
  "updated": 1767558765148,
  "link": null,
  "locked": false
}
```

**Minimal format** (20-50% smaller, loads correctly):
```json
{
  "id": "box-1",
  "type": "rectangle",
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 80,
  "strokeColor": "#1e1e1e",
  "backgroundColor": "transparent",
  "fillStyle": "solid",
  "strokeWidth": 2,
  "strokeStyle": "solid",
  "roughness": 1,
  "opacity": 100,
  "frameId": null,
  "index": "a0",
  "roundness": { "type": 3 },
  "boundElements": [{ "type": "text", "id": "box-1-text" }]
}
```

### File Size Optimization

Use `scripts/optimize_excalidraw.py` to remove auto-generated fields:

```bash
python scripts/optimize_excalidraw.py diagram.excalidraw --dry-run  # Preview
python scripts/optimize_excalidraw.py diagram.excalidraw           # Apply
```

Typical savings: **20-50%** file size reduction.

## Text Inside Shapes (Labels)

**Every labeled shape requires TWO elements:**

### 1. Shape with boundElements

```json
{
  "id": "my-box",
  "type": "rectangle",
  "boundElements": [{ "type": "text", "id": "my-box-text" }]
}
```

### 2. Text with containerId

```json
{
  "id": "my-box-text",
  "type": "text",
  "x": 105,
  "y": 120,
  "width": 190,
  "height": 50,
  "text": "Component\nSubtitle",
  "fontSize": 20,
  "fontFamily": 5,
  "textAlign": "center",
  "verticalAlign": "middle",
  "containerId": "my-box",
  "originalText": "Component Subtitle",
  "lineHeight": 1.25
}
```

**DO NOT use the `label` property** - it only works in the JavaScript API, not raw JSON.

### Text Positioning

- Text `x` = shape `x` + 5
- Text `y` = shape `y` + (shape.height - text.height) / 2
- Text `width` = shape `width` - 10

## Frames for Grouping

Use frames instead of dashed rectangles for logical groupings:

```json
{
  "id": "frame-1",
  "type": "frame",
  "x": 100,
  "y": 100,
  "width": 500,
  "height": 300,
  "name": "Phase 1: Setup"
}
```

Elements inside a frame should have `"frameId": "frame-1"`.
